## v1.2.0 更新內容

### GIF 匯出修正
- 修正 spine-exporter 匯出時可能裁掉角色頂部、底部的問題。
- 依完整動畫計算畫面邊界，保留角色動作範圍與少量安全邊距。

### 圖鑑與資料管理
- 已保存的圖鑑改放在獨立的 `library/heroes/`，與可清理的 output 分開。
- 舊 `output/heroes/` 在閒置時自動搬移；同名資料保留，不直接覆寫。
- 舊圖鑑若借用執行記錄中的 GIF，會先保存 GIF，再允許清理執行資料。
- 新增英雄刪除按鈕，將圖鑑及同英雄歷史執行副本移至 `output/trash/` 回收區。
- 新增「清理執行資料」，確認後永久清除 `output/runs/`、`output/temp/`，保留已保存圖鑑、資源索引與回收區。
- 工作執行中禁止清理、保存及刪除，並驗證檔案路徑，防止誤操作。

### 圖片瀏覽與分享
- 圖鑑列表採用小型靜態縮圖，減少同時播放 GIF 的負擔。
- 詳情 GIF 移上播放、移開停止；點圖片開啟完整原檔。
- 新增第三張透明 PNG 主圖，保留 GIF 代表影格的原尺寸、透明背景及完整畫布。
- 主圖支援複製、下載；各 GIF 支援複製原尺寸靜態 PNG。
- 複製成功後可貼上至支援圖片貼上的社群平台；不支援圖片剪貼簿的瀏覽器可改用下載 PNG。

### 升級提醒
- 更新程式後重啟 server，並重新整理瀏覽器。
- 未保存的執行結果需先按「移至圖鑑」，再清理執行資料。
- 複製內容是靜態 PNG；透明度是否保留取決於接收平台。
- 此版本的匯出修正作用於重新匯出的 GIF，無法補回舊檔已被裁掉的像素。
- 不包含遊戲素材或外部工具；GitHub 提供此版本的原始碼 ZIP / TAR 下載。
